# Folder Open Tabs

Zen Browserのフォルダ内で、アンロードされていないタブを枠線で区別する個人用CSS Modです。フォルダを閉じても、そのタブを表示します。

## 表示

| タブの状態 | フォルダ展開中 | フォルダを閉じた後 |
| --- | --- | --- |
| 現在表示しているタブ | Zen標準の選択背景 | 表示を維持 |
| アンロードされていない、選択されていないタブ | 輪郭に細い枠線 | 枠線付きで表示 |
| アンロード済みのタブ | 枠線なし | 非表示 |

枠線は文字色に合わせた半透明色です。タブの大きさを変えず、選択中の背景を上書きしません。入れ子のフォルダでは、対象タブまでのフォルダ階層も残します。

判定にはタブの `pending` / `discarded` 属性を使用します。「今回クリックした履歴」を記録する仕組みではありません。クリックして開いたタブでも、その後アンロードされれば枠線と折り畳み後の表示が消えます。セッション復元などで読み込まれたタブも対象です。

## 導入

作成時点では、通常利用しているZenのプロファイルには適用していません。

1. Zenで `about:support` を開き、「プロファイルフォルダー」を開きます。
2. 既存の `chrome/userChrome.css` がある場合は、先にバックアップします。`chrome` フォルダーがなければ作成します。
3. このプロジェクトの `chrome.css` を、プロファイル内の `chrome/folder-open-tabs.css` としてコピーします。
4. このプロジェクトの [`chrome/userChrome.css`](chrome/userChrome.css) を、プロファイル内の `chrome/userChrome.css` としてコピーします。既存の `userChrome.css` がある場合は、上書きせず、ファイル末尾に次の行を追加します。

   ```css
   @import url("folder-open-tabs.css");
   ```

5. `about:config` で `toolkit.legacyUserProfileCustomizations.stylesheets` を `true` にします。
6. Zenを再起動します。

`chrome/userChrome.css` はZenプロファイルから読み込む入口ファイルです。プロジェクト内にもコピー用テンプレートを置いています。これはローカルの `userChrome.css` 経由で読み込む方法です。Zen Modsのストア登録や自動更新は使用しません。既存の自動生成ファイル `zen-themes.css` は編集しないでください。

取り外す場合は、追加した `@import` の行を削除してZenを再起動します。他の個人用CSSがある場合、そのファイルやスタイルシート設定はそのまま残してください。

## 確認済みの範囲

Windows版Zen Browser 1.22.2bの実行ファイルを使用し、通常プロファイルから隔離したヘッドレス環境で確認しました。

- フォルダを閉じた後の選択中・読み込み済み・アンロード済みタブの表示。
- 残ったタブのマウス選択と、選択変更に伴う枠線の移動。
- フォルダ展開後のアンロード済みタブの再表示。
- 選択中タブがフォルダ外にある場合と、入れ子のフォルダ。
- タブをアンロードした直後の表示更新。

テスト実行は `node tests/zen-smoke.mjs`。Node.jsと `C:/Program Files/Zen Browser/zen.exe` が必要です。ワークスペース内に専用テストプロファイルを作成します。

## 制約

**これは表示を変更するCSS版です。Zen内部のタブ管理は変更しません。** 折り畳み後に追加表示した非選択タブについて、内部の `tab.visible` が `false`、`aria-hidden` が `true` のままになる挙動を実機で確認しました。

マウスでの選択はテストを通過しています。一方、内部の表示判定を利用するキーボード移動やドラッグ操作、スクリーンリーダーとは不整合が残ります。CSSでこれらの属性や内部一覧を修正することはできません。内部動作まで一致させる場合は、通常のCSS Modとは別にブラウザー本体の対応などを検討する必要があります。

Split View、Live Folders、別OS、他のModとの併用は未検証です。Zenのフォルダアニメーションが設定する高さや余白を上書きするため、折り畳み時の動きは標準と異なります。将来のZen更新で内部構造が変わった場合は再確認が必要です。
