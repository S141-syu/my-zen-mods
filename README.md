# Folder Open Tabs

Zen Browserのフォルダー内にある、アンロードされていないタブを枠線で区別する個人用CSS Modです。フォルダーを閉じても、対象のタブを表示したままにします。

## 表示

| タブの状態 | フォルダーを開いているとき | フォルダーを閉じたとき |
| --- | --- | --- |
| 現在表示しているタブ | Zen標準の選択中背景 | 表示を維持 |
| アンロードされていない非選択タブ | 輪郭に細い枠線 | 枠線付きで表示 |
| アンロード済みのタブ | 枠線なし | 非表示 |

枠線にはタブの文字色を基準にした半透明色を使います。タブの大きさは変えず、選択中の背景色も上書きしません。サイドバーのタブ背景、ロード済みタブの枠線、ホバー背景を13px、タブの閉じる・アンロードボタンとフォルダーのアンロードボタンを8pxの角丸へ調整します。入れ子になったフォルダーでは、対象のタブまでのフォルダー階層も残します。

## 表示の判定

タブの判定には、タブ要素の `pending` / `discarded` 属性を使います。クリックしたタブの履歴を記録する仕組みではありません。クリックして開いたタブでも、その後アンロードされると、枠線とフォルダーを閉じた後の表示が消えます。セッション復元などで読み込まれたタブも対象です。

## 導入

このプロジェクトの作成時点では、普段使っているZenのプロファイルには適用していません。

1. Zenで `about:support` を開き、「プロファイルフォルダー」を開きます。
2. 既存の `chrome/userChrome.css` がある場合は、先にバックアップします。`chrome` フォルダーがなければ作成します。
3. このプロジェクトの `chrome.css` を、プロファイル内の `chrome/folder-open-tabs.css` としてコピーします。
4. このプロジェクトの [`chrome/userChrome.css`](chrome/userChrome.css) を、プロファイル内の `chrome/userChrome.css` としてコピーします。既存の `userChrome.css` がある場合は上書きせず、ファイル末尾に次の行を追加します。

   ```css
   @import url("folder-open-tabs.css");
   ```

5. `about:config` で `toolkit.legacyUserProfileCustomizations.stylesheets` を `true` にします。
6. Zenを再起動します。

`chrome/userChrome.css` は、Zenのプロファイルから読み込む入口ファイルです。プロジェクト内にもコピー用テンプレートを置いています。この方法では、プロファイル内の `userChrome.css` からCSS Modを読み込みます。Zen Modsストアへの登録や自動更新には対応していません。既存の自動生成ファイル `zen-themes.css` は編集しないでください。

取り外すときは、追加した `@import` の行を削除してZenを再起動します。他の個人用CSSがある場合は、そのファイルやスタイルシート設定を変更する必要はありません。

## 確認済みの範囲

Windows版Zen Browser 1.22.2bを使用し、普段使っているプロファイルとは別のヘッドレス環境で確認しました。

- フォルダーを閉じた後の、選択中・読み込み済み・アンロード済みタブの表示。
- 残ったタブのマウス選択と、選択変更に伴う枠線の移動。
- フォルダーを開いた後の、アンロード済みタブの再表示。
- 選択中のタブがフォルダー外にある場合と、フォルダーが入れ子になっている場合。
- タブをアンロードした直後の表示更新。

テストは `node tests/zen-smoke.mjs` で実行できます。Node.jsと `C:/Program Files/Zen Browser/zen.exe` が必要です。実行すると、ワークスペース内に専用のテストプロファイルを作成します。

## 制約

このModは表示だけを変更するCSS版であり、Zen内部のタブ管理は変更しません。フォルダーを閉じた後に追加表示する非選択タブでは、内部の `tab.visible` が `false`、`aria-hidden` が `true` のままになることを実機で確認しています。

マウスによるタブの選択はテスト済みです。一方、内部の表示判定を使うキーボード移動やドラッグ操作、スクリーンリーダーとは整合しません。CSSからこれらの属性や内部一覧を修正することはできません。内部動作まで一致させるには、通常のCSS Modとは別に、Zen本体側の対応を検討する必要があります。

Split View、Live Folders、別OS、他のModとの併用は未検証です。フォルダーを閉じるときは、アンロード済みタブだけを180msで縮小・フェードし、ロード済みタブは表示を維持します。再び開くときもロード済みタブの位置を維持し、アンロード済みタブだけを展開します。Zenの将来の更新で内部構造が変わった場合は、再確認が必要です。
